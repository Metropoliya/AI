# Реалистичный русский голос для AI-аватара — итоги исследования

> Два прогона deep-research (2026-07-18 и 2026-07-20), суммарно 210 агентов,
> 32 подтверждённых факта — каждый проверен по первоисточникам тремя независимыми
> агентами-скептиками. Только то, что выжило проверку.

## Вывод одной строкой

Максимальный реализм русского голоса = **ElevenLabs Professional Voice Clone (PVC)
по 1–3 часам студийной русской записи** на модели `eleven_multilingual_v2` с настройками
Stability 0.4–0.5 / Similarity 0.75 / Style 0–0.3 → готовое аудио → липсинк
(Higgsfield Wan-конвейер или standalone-модели через WaveSpeedAI).

## 1. Higgsfield (текущая платформа) — из прогона №1

- Клон голоса — родная функция: Voiceover/Change Voice → Voice Preset → Add Voice →
  загрузка MP3/WAV или запись **до 2 мин** → Clone Voice. API: `create_voice…` (10 сек–3 мин).
  Лимит ~3 клона на аккаунт. Это **instant-клон** — потолок реализма задаёт образец.
- Движок рендера выбирается **на каждую генерацию**: `text2speech_v2` + variant =
  `elevenlabs` (дефолт) | `minimax` (рекомендован для цифровых двойников) | `seed_speech`
  | `vibe_voice` | `cozy_voice`. Один клон можно гонять через все и сравнивать.
  ⚠️ Эмпирика проекта: MiniMax отдаёт звук ~на 25 дБ тише — нормализовать до −14 LUFS.
- Живость подачи — только разметкой текста (Speak 2.0): ЗАГЛАВНЫЕ=акцент, «…»=пауза,
  [смеётся]/[шёпотом]=эмоции, длинные промпты естественнее. Слайдеров нет.
- Русский на страницах Higgsfield явно не назван (только «74+ языков») → надёжный
  маршрут: **клон → готовое аудио → липсинк**, не промпт-генерация речи видеомоделью.
- Голос к аватару Marketing Studio в UI не привязывается (проверено владелицей).
- Рабочий конвейер проекта (проверен, одобрен визуально/по звуку):
  «текст → MiniMax/EL-клон → loudnorm −14 LUFS → Wan 2.7 (start_image=аутпейнт 9:16 фото,
  audio_references=дорожка, промпт с живой камерой) → авто-проверка».

## 2. ElevenLabs — как поднять реализм НА ПОРЯДОК (прогон №2)

- **PVC официально поддерживает русский** (🇷🇺 в списке). Ключевое: записывать
  обучающие сэмплы **именно на русском** — клон с записи на другом языке даёт акцент.
- **Требования к записи PVC**: минимум 30 мин, оптимум **2–3 часа**; студийное
  качество: один голос, без шума/реверба/слов-паразитов; −23…−18 dB RMS, true peak −3 dB.
  PVC клонирует «почти идеально, включая дефекты» — мусор в записи = мусор в клоне.
- **PVC заметно реалистичнее Instant-клона** (позиция самого ElevenLabs).
- **Цены**: Instant-клон — со Starter $6/мес; **PVC — с Creator $22/мес** (первый месяц $11).
- **Модель для рилсов**: `eleven_multilingual_v2` (самая lifelike и стабильная,
  29 языков вкл. русский, лимит 10k символов). `eleven_v3` — экспрессивнее, но
  нестабильнее и лимит 5k. Для talking-head — **multilingual_v2**.
- **Настройки** (официальные рекомендации): разговорная речь — stability **0.4**,
  similarity **0.75**, style **0.3**; универсальный старт — 0.5/0.75/0.
  Style держать ближе к 0 (жрёт стабильность), Speaker Boost — эффект малозаметен.

## 3. HeyGen — если захочется аватара «из своего видео»

- **Custom Digital Twin** (аватар из собственного футажа) есть даже на **Free** (тест:
  3 видео/мес, 1 мин, водяной знак). Рабочий план — **Creator $29/мес** (без водяного
  знака, 1080p, клон голоса, 175+ языков).
- **Прямая интеграция ElevenLabs**: Voice → + New Voice → Integrate 3rd Party Voice →
  вставить API-ключ ElevenLabs → русский PVC-клон появляется в списке → Set Primary
  Voice у своего аватара. Ровно наш сценарий.
- **API**: Pay-As-You-Go от $5 без подписки (генерация видео с готовым аватаром),
  НО создание Custom Digital Twin через API — только Enterprise. Для автозавода:
  аватар создаётся один раз в UI, дальше видео гоняются по API.

## 4. Standalone-липсинк (видео+аудио) — 2026

- Агрегатор **WaveSpeedAI**: 41 модель липсинка/аватаров через один REST API,
  оплата за генерацию, **$1 бесплатных кредитов на тест**. Включает:
  sync.so Lipsync-2-Pro и Lipsync-3, ByteDance LatentSync, OmniHuman 1.0/1.5, Wan 2.2 S2V.
- Практично: прогнать одно русское аудио через несколько движков и выбрать лучший
  липсинк, не заводя подписки.

## 5. Что осталось непроверенным (честно)

- Слепое сравнение качества русского липсинка HeyGen Avatar IV vs Higgsfield vs
  sync.so/LatentSync — нужен практический A/B на бесплатных кредитах.
- Связки из русскоязычных YouTube-гайдов 2025–26 — верифицированных источников не нашлось.
- Точная цена 30–60-сек рилса через HeyGen PAYG API (посекундная ставка не опубликована).
